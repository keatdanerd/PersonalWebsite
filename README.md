# keatonraney.com: site files

Drop these files into the root of your site, next to your existing `Images/` and `Videos/` folders. Every image and video path stays the same as before, so nothing needs to be renamed. The new `index.html` replaces the old one.

```
index.html      Home: video hero, bio, links to the other pages, news
research.html   Current and past research, plus presentations
honors.html     Honors & awards
teaching.html   Teaching, leadership & service
cv.html         Web CV; the "Save as PDF" button prints a clean PDF
beyond.html     Drawing, running, reading, science & faith
contact.html    Contact
favicon.svg     Browser-tab icon (KR monogram)
assets/css/site.css   All styles (colors and fonts are set at the top)
assets/js/site.js     Mobile menu, scroll effects, email link
```

## Things to update over time
- **New photos:** The Quantum Sensing project on `research.html` uses a diagram. Swap in a photo of your UT setup when you have one.
- **Publications:** Add them to the Presentations & Publications list on `research.html` and to `cv.html`.
- **Google Scholar and ORCID:** There's a commented-out template in `contact.html`.
- **"Last updated" date:** Search each page for "Last updated November 2026" and change it.
- **Colors:** Edit `--accent` (UT burnt orange) and `--ink` at the top of `site.css`.
